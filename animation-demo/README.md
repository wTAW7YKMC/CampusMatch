# 校易配 - 交互式动画演示Demo

## 概述

这是一个单文件HTML交互动画演示，真实模拟用户使用"校易配"校园二手智能交易平台的核心操作流程。演示以手机屏幕为视觉载体，通过模拟光标移动、点击、输入等操作，配合GSAP动画引擎，完整展示6个关键场景的用户交互路径。

---

## 快速开始

### 运行方式

直接双击打开 `index.html` 或拖入浏览器即可运行。

**浏览器要求**：Chrome 90+ / Firefox 88+ / Safari 14+ / Edge 90+

### 操作方式

| 操作 | 方式 |
|------|------|
| 播放/暂停 | 点击 ▶ 按钮 或 按空格键 |
| 停止/重播 | 点击 ⏹ 按钮 或 按 R 键 |
| 下一场景 | 按 → 方向键 |
| 上一场景 | 按 ← 方向键 |
| 跳转场景 | 点击底部章节按钮（1启动 ~ 6卖家） |
| 拖拽进度 | 点击底部进度条任意位置跳转 |
| 倍速切换 | 点击 1x 按钮，切换 1x/1.5x/2x |

## 六幕场景

### 场景1：应用启动（0-8秒）
- 浏览器地址栏显示 `campustrade.ai`
- 校易配Logo淡入，脉冲光环动画
- "正在启动智能交易系统..." 逐字显示
- 蓝黄渐变进度条 0%→100%
- 文字依次变化："启动→加载引擎→准备就绪"

### 场景2：首页浏览（8-20秒）
- 完整首页界面（导航栏 + Hero区 + 分类区 + AI功能区 + 商品瀑布流 + 数据看板）
- 光标依次移动到：智能匹配卡片 → 教材分类 → 商品卡片
- 模拟悬停效果和点击涟漪
- 页面滚动展示AI功能区和推荐商品
- 数据看板数字滚动动画（2580 / 1200 / 860）

### 场景3：智能匹配（20-45秒）⭐核心
- 进入智能匹配页，点击输入框
- 逐字输入需求："我想买一本管理学教材"
- 点击示例标签，自动添加预算条件
- 点击"开始匹配"按钮
- AI分析动画：大脑脉冲 + 文字轮播 + 进度条
- 显示3件匹配商品卡片（96%/88%/82%匹配度）
- 推荐理由逐个弹出

### 场景4：商品详情（45-60秒）
- 查看商品大图、点击缩略图切换
- 展开全文描述、点击收藏（心形变红）
- AI智能问答展开、复制回复
- 联系卖家弹窗

### 场景5：智能发布（60-90秒）⭐核心
- 选择商品类别→输入名称→输入价格
- 获取AI价格建议
- 选择成色、使用时长、交易地点
- 补充说明逐字输入
- 点击"AI生成商品信息"
- AI生成动画→展示预览卡片
- 价格可视化评估条、成交概率环形图（85%）
- 编辑标题→最终发布→Toast提示

### 场景6：卖家助手（90-105秒）
- 数据概览数字滚动（在售1/浏览128/咨询5/成交8）
- 商品表现数据展开（浏览量/咨询率/收藏数）
- AI建议提示
- 快捷回复工具、价格优化建议

## 技术实现

| 层级 | 技术 | 说明 |
|------|------|------|
| 结构 | HTML5 | 6个场景容器 + 控制面板 + 光标层 |
| 样式 | CSS3 + CSS变量 | 武汉理工大学蓝黄设计系统 |
| 动画 | GSAP 3.12 | Timeline控制、补间动画、序列编排 |
| 交互 | Vanilla JS | 播放/暂停/跳转/倍速/键盘快捷键 |

### 核心类

- **CursorController**：模拟光标移动、点击、涟漪效果
- **InputSimulator**：逐字打印文本、表单填充
- **SceneSwitcher**：场景间转场动画（淡入淡出）
- **PlaybackController**：播放控制、进度管理、倍速切换

### 设计系统（武汉理工大学蓝黄配色）

- 主品牌蓝：`#2061CA`
- 主强调黄：`#E6A000`
- 蓝深：`#0A1F44` / 蓝浅：`#D6E8FC`
- 黄深：`#C78A00` / 黄浅：`#FFF0B3`

### 外部依赖
